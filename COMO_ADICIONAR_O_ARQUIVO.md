# Como adicionar o arquivo Dashboard_Vendas.xlsx

O repositório já está pronto com o README profissional.

## Passo a passo rápido (2 minutos):

1. Acesse: https://github.com/Marcosmto/sales-dashboard-excel
2. Clique no botão **Add file** → **Upload files**
3. Arraste o arquivo `Dashboard.xlsx` (ou renomeie para `Dashboard_Vendas.xlsx`)
4. Coloque na raiz do repositório
5. Escreva uma mensagem de commit, por exemplo: `Add Dashboard_Vendas.xlsx`
6. Clique em **Commit changes**

Pronto! O arquivo aparecerá no repositório.

---

## Dica extra (opcional)

Se quiser organizar melhor:
- Coloque o arquivo principal como `Dashboard_Vendas.xlsx` na raiz
- Crie a pasta `data/` e coloque uma cópia da base lá se desejar
